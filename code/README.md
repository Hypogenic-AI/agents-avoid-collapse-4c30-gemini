# Cloned Repositories

## Repo 1: dataset-contamination
- URL: https://github.com/moskomule/dataset-contamination
- Purpose: Provides tools to simulate the contamination of datasets with generative models (like DALL-E, Stable Diffusion) and evaluate the performance degradation over iterations, simulating model collapse.
- Location: code/dataset-contamination/
- Key files: `main.py`, `generate.py`
- Notes: Useful baseline code for generating contaminated data and studying the effects of recursively generated data on model distributions.
